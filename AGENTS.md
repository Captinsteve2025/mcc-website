# Agent development instructions

Every development session on this repository MUST read and apply:

- `BRAND_GUIDE.md` — the mandatory MCC styling packet. Read it and inspect the established website components before beginning any new page migration. Seek Steve’s approval before introducing new palettes, fonts, or design conventions.
- `MCC_PRODUCT_STANDARDS.md` — the commercial quality bar and the ten assessment criteria (functional correctness, premium visual presentation, customer experience, engagement, conversion, mobile, performance, accessibility, SEO, production browser verification).
- `MCC_PRODUCT_IMPROVEMENT_REGISTER.md` — the status register for every component. Update it when implementing, deploying or verifying work. An implemented component is not automatically complete.

Standing boundaries: never modify the enquiry system, database configuration, email notifications, CYA booking integration or SEO migration configuration without explicit instruction. Never fabricate CYA content — display exactly what the data supplies, and preserve complete original content in a collapsed panel when reliable extraction is impossible.
